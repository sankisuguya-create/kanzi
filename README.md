# 3年生 かんじドリル

小学3年生が自分で予習・復習する漢字ドリル（配当漢字200字）。

- **よしゅう**: 新しい字の筆順アニメ・例語・読み上げを見て、1回なぞる（5字ずつ）
- **よむ**: 漢字の読みをキーボードで入力（ローマ字は自動でひらがな）。自動採点して次へ
- **かく**: 読みを見てタッチペンで書く（なぞる→ヒント→じぶんで、1画ずつ判定）。自動で次へ
- **カード**: かんじ→よみ／よみ→かんじのフラッシュカード。タップで答え、もう一度タップで次へ
- **メニュー**: 自分の取り組みで木が育つ。他の児童との比較は出さない
- **先生用**: 授業の進度の設定、学級でつまずいている字（児童名なし）、予習の順番の貼り付け
- **書き順を大きく見せる（先生）**: 1〜5字を選ぶと、1字ずつ画面いっぱいに（十字の点線つきで）書き順を再生（左に訓読み・右に音読み、縦書き）。クリック・→で次、←で前、Esc で終了。最後の字の次は選んだ字をならべて書き順をくり返し再生（読みは出さない）。モニターに映して使う
- **先生のおためし**: 先生画面の「児童画面を ためす」で児童画面をそのまま使える。「1日すすめる」で翌日以降の出題、「かく問題を 出す」で書き問題をすぐ試せる。記録はその端末だけに残り、スプレッドシートには送らない

設計書: [docs/design.md](docs/design.md) ／ 根拠: [docs/research.md](docs/research.md)

## 試す（ブラウザだけ・この端末に保存）

`index.html` をブラウザで開く。先生画面は `index.html?teacher=1`（架空のデータ）。

## 学校で使う（Google Apps Script）

1. 新しいスプレッドシートを作り、「拡張機能 → Apps Script」を開く。
2. `gas/` の4ファイル（`Code.js`・`Scheduler.js`・`Index.html`・`appsscript.json`）を同じ名前で貼る（clasp を使う場合は `gas/` を push）。
3. エディタで関数 `setup` を1回実行する（シート「名簿」「進捗」「設定」ができる）。
4. 「名簿」に児童のメールアドレスと組を入れる（例: `12345678@kyoiku.edu.nishi.or.jp` ／ `3-1`）。
5. 「デプロイ → 新しいデプロイ → ウェブアプリ」。実行ユーザー＝自分、アクセス＝ドメイン内。
6. 児童アカウントで開き、メニューが出ることを確かめる（メールアドレスが取れない設定だとエラー画面になる）。
7. 先生アカウントで開き、「よしゅうの順番を変える」に光村図書の新出順（教科書巻末の一覧）を貼り付ける。

- 児童の画面には本人の記録しか送らない。先生画面は字ごとの集計だけで、児童名は出さない。
- 答えはまず端末に保存し、10問ごと・画面を閉じる時にまとめて送る。通信できない時は端末に残し、次に開いた時に送る。

## 開発

```
npm install        # 検査用の辞書（kanjidic2-json）と形態素解析（kuromoji）
npm run build      # data-src/ と KanjiVG から src/*-g3.js、src/ から gas/Index.html を生成
npm test           # 出題計算・データの検査
npm run e2e        # Chromium で通し操作（playwright-core と CHROMIUM が必要）
```

- 例語・読みを直すときは `data-src/words-g3.txt` を編集して `npm run build`。生成物（`src/data-g3.js` など）は直接編集しない。
- `src/` を変えたら `npm run build:gas` で `gas/Index.html` を作り直す。
