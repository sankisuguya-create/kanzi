# 漢字の森（小学1〜6年）

小学生が自分で予習・復習する漢字ドリル「漢字の森」（学年別漢字配当表の1026字）。先生が組ごとに見せる学年を選ぶと、児童のメニューはいちばん上の学年のタブで開き、上部のタブで学年を切り替えられる。

- **漢字を ぜんぶ見る**: 学年の全字の一覧。「見る」で押すと、右に先生の提示画面と同じ表示（外枠・十字・うす文字の上を黒で書き順・ふりがな）、左にその字を使ったことば。「えらぶ」で押すと、問題に出す字に選べる
- **よむ**: 漢字を見て読みをキーボードで入力（ローマ字は自動でひらがな）。送り仮名は答えに入れない（悪い → わる）。自動採点して次へ
- **かく**: 読みを見て、見本なしでタッチペンで書く。1画ずつ判定し、同じ線を2回続けてまちがえたら正しい書き順を見せて次へ
- **カード**: かんじ→よみ／よみ→かんじのフラッシュカード。画面のどこを押しても 答え → 次。よみは上・漢字は下に固定し、答えの場所は はじめからとっておく（答えが出ても字が動かない）
- **えらんだ漢字を見る**: 選んだ字を1字ずつ「見る」の表示で
- よむ・かく・カードは、出す字を「次の漢字テストの範囲（先生が指定した時だけ）／おすすめ（わすれそうな字）／えらんだ漢字／ならった漢字から ランダム／まちがいの多い漢字」から選ぶ。終わると出た字の一覧（○×）を出し、チェックを外すと選択から外れる
- **メニューの木**: よむ・かく・カードを最後まで終えた時だけ、その回の問題数だけ育つ。他の児童との比較は出さない
- **次の漢字テストの範囲（先生）**: 学級ごとに名前と字を指定（学年をまたいでよい、押すたびに自動保存）。児童のメニューに「次の漢字テストの範囲を見る」が出て、よむ・かく・カードでその字を練習できる
- **先生用**: 担当学級（スプレッドシートの「教師」シートで自動）の子どもごとの記録（最後に使った日・終えた回・おぼえた字・まちがいの多い字。児童には見せない）、見せる学年、学年ごとの授業の進度（「ならった漢字」の範囲）、学級でつまずいている字（児童名なし）、出題順の貼り付け。設定（見せる学年・テストの範囲・進度・出題順）は開閉式で、閉じていても いまの値が見出しに出る。先生画面のデータは学級ごとに1回の通信で読む
- **書き順を大きく見せる（先生）**: 1〜6字を選ぶと、全画面で1字ずつ画面いっぱいに（外枠と十字の点線つき、設定でうすい完成形の下地つき）書き順をくり返し再生（左に訓読み・右に音読み、縦書き）。クリック・→で次、←で前、Esc で終了。最後の字の次は選んだ字をならべて書き順をくり返し再生（読みは出さない）
- **先生のおためし**: 先生画面の「児童画面を ためす」で児童画面をそのまま使える。「1日すすめる」で翌日以降の「おすすめ」を試せる。記録はその端末だけに残り、スプレッドシートには送らない

設計書: [docs/design.md](docs/design.md) ／ 根拠: [docs/research.md](docs/research.md)

## 試す（ブラウザだけ・この端末に保存）

`index.html` をブラウザで開く。先生画面は `index.html?teacher=1`（架空のデータ）。

## 学校で使う（Google Apps Script）

1. 新しいスプレッドシートを作り、「拡張機能 → Apps Script」を開く。
2. `gas/` の4ファイル（`Code.js`・`Scheduler.js`・`Index.html`・`appsscript.json`）を同じ名前で貼る（clasp を使う場合は `gas/` を push）。
3. エディタで関数 `setup` を1回実行する（シート「名簿」「教師」「進捗」「設定」ができる）。
4. 「名簿」に児童を1人1行で入れる: `メール | 学年 | 組 | 番号 | 名前`（例: `12345678@kyoiku.edu.nishi.or.jp | 3 | 1 | 5 | やまだ たろう`）。学年と組から学級「3年1組」が決まり、その学年が児童に見える（先生画面で変えられる）。
   「教師」に先生の担当を入れる: `メール | 学年 | 組`。1人で何行でも書ける。組を空けると その学年の全学級（学年主任など）。先生は担当学級だけを見られ、変えられる。
5. 「デプロイ → 新しいデプロイ → ウェブアプリ」。実行ユーザー＝自分、アクセス＝ドメイン内。
6. 児童アカウントで開き、メニューが出ることを確かめる（メールアドレスが取れない設定だとエラー画面になる）。
7. 先生アカウントで開き、組ごとに「児童に見せる学年」を選ぶ。必要なら学年ごとに授業の進度を押し、「出題順を変える」に光村図書の新出順（教科書巻末の一覧）を貼り付ける。

- 児童の画面には本人の記録しか送らない。先生画面は字ごとの集計だけで、児童名は出さない。
- 答えはまず端末に保存し、10問ごと・画面を閉じる時にまとめて送る。通信できない時は端末に残し、次に開いた時に送る。

## 開発

```
npm install        # 検査用の辞書（kanjidic2-json）と形態素解析（kuromoji）
npm run build      # data-src/ と KanjiVG から src/*-g3.js、src/ から gas/Index.html を生成
npm test           # 出題計算・データの検査
npm run e2e        # Chromium で通し操作（playwright-core と CHROMIUM が必要）。各画面で使われたフォントに中国語フォントが無いことも調べる
npm run build:font # 同梱の日本語フォント src/fonts/ を作り直す（python3 の fonttools・brotli が必要）
```

- 例語・読みを直すときは `data-src/words-gN.txt`（N=学年）を編集して `npm run build`。生成物（`src/data.js`・`src/strokes.js`）は直接編集しない。
- `src/` を変えたら `npm run build:gas` で `gas/Index.html` を作り直す。

## フォント（中国語フォントを出さない）

- 文字は日本語フォントだけで描く。指定の順: BIZ UDPゴシック → Noto Sans JP / Noto Sans CJK JP（Chromebook）→ ヒラギノ（Mac・iPhone）→ 游ゴシック・メイリオ（Windows）→ IPA フォント → **同梱の日本語フォント**（`src/fonts/`、Noto Sans JP から常用漢字・人名用漢字・かな・英数字を切り出したもの）。漢字を大きく見せる所は教科書体・明朝を先に並べ、無ければ同じ日本語ゴシックに落ちる。
- 同梱フォントは端末の日本語フォントで足りる時は読み込まれない。読み込み中に別のフォントで仮表示しない（`font-display: block`）。
- GAS 版は同じ Noto Sans JP を Google Fonts から受け皿として読む。
- ページは `lang="ja"`（JS でも付ける）。
