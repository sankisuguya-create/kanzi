# kanzi — 漢字学習サイトの設計

小学校の児童が漢字を学習するための Web アプリの設計書。
設計理念は `-` リポジトリの [サイト設計理念](https://github.com/sankisuguya-create/-/blob/main/principles/site-design-philosophy.md)・[低コスト評価軸](https://github.com/sankisuguya-create/-/blob/main/principles/low-cost-evaluation-axes.md) に従う。

## 結論

**「よむ」「かく」の2モード構成。両方とも先行研究の実証上・実装上の根拠が十分あるため、両方作る。**

- 「よむ」: フラッシュカード式。漢字・漢字語を出して読みを想起させ、自己採点。間隔反復（簡易 Leitner）で復習を自動スケジュールする。
- 「かく」: 書き順つきのなぞり→単独書き。KanjiVG の筆順データ + ストローク判定ライブラリで「書く」は実装可能（難しくない）。段階的提示（研究上の「体性感覚法」相当）で実装する。

ユーザーの依頼文「書くが難しいなら読む&フラッシュカード方式で」に対する答え: **書くは難しくない**（後述・実装方式）。ただし先行研究上「読み先行」が効率的なので、**デフォルトの学習流路は よむ→かく** とし、よむを優先実装する。

## 先行研究の調査結果（設計の根拠）

### 1. 読みと書きは別の認知過程 —「読み先行」が効率的

- **読み先習の法則（澤柳政太郎, 1920頃）**: 「読むこと」と「書くこと」は別の認識の働きであり、読みを先行させた方が少ない労力で同等の効果。成城小学校の実験では読み先行で1年生末に読み平均500字・（教えていない）書き200字が習得された。
- 学習指導要領でも「当該学年配当の漢字は読むこと、前の学年配当の漢字は書くこと」と読み先行の順序が採られている。

**設計への反映**: 新出漢字は「よむ」モードで先に接触させ、定着してから「かく」へ回す。書きは読み定着後の遅延再生として位置づける。

### 2. 記憶には「目視+想起」が有効 — 書字は必須ではない

- 谷口（書字動作の効果, J.JET 36別冊）: 未知漢字の記憶で、書字条件より**目視条件の方が手がかり再生の成績が高かった**。書字は字形-意味連合の獲得を必ずしも促進しない（むしろ干渉する場合あり）。
- Thomas (2015, Language Learning): **空書き（kūsho）は受動的視察よりも反復筆写よりも高い正答率**（小さいが有意な優位）を示した。運動表象の関与。
- 筆記回数と再生成績（特別支援学級, 日本特殊教育学会系誌）: 3回〜7回の筆記回数差は再生成績にほぼ効かず、**学習方法の差の方が効いた**。「10回書きなさい」式の反復には根拠がない。

**設計への反映**: 「よむ」では書かせず**想起+呈示確認**に絞る。書きの反復回数は固定ノルマにせず、間隔反復の再出題で代替する。

### 3. 刺激ペアリング（文字+音声+意味の対呈示）で読みが獲得できる

- Omori & Yamamoto (2013b): PCで漢字（文字刺激）・読み音声（音声刺激）・意味イラスト（意味刺激）を対呈示する手続きで、ASD/ADHD児が漢字の読みを獲得し2週間維持・文中への般化も確認。
- クラスワイド実施（小学4年通常学級, JALD 27(3)）: プロジェクタで同様の手続きを行い、読み書きテストの平均正答数と全問正答児童の割合が増加。

**設計への反映**: フラッシュカードの裏面は「読み＋意味を示す最小情報（例: 代表熟語や短い説明）」とし、文字→音声→意味を1操作で呈示する。音声は Web Speech API（`speechSynthesis`）で読み上げ可能にし、刺激ペアリングの3要素を揃える。

### 4. 想起練習（テスト効果）— 児童への効果は実証済みだが条件つき

- Goossens et al. (2013/2014): 小学校の語彙学習で想起練習は再学習より再生（再生想起）を高めた（認識課題では差なし）。
- Karpicke & Roediger系の想起練習は児童でも有効（Frontiers in Psychology 2016, 平均10歳）。
- ただし多教室フィールド研究（Applied Cognitive Psychology, Goossens et al. 2016）では長ラグ反復・想起練習の優位が出ず、**実教室では効果が出ない場合もある**報告がある。

**設計への反映**: カードは必ず「まず想起させてから裏を見せる」構造にする（答えを見てから丸めても学習にならない）。想起失敗時は即フィードバックで正しい結合を再度呈示する。

### 5. 分散学習・間隔反復 — 同部首漢字にも効果あり

- 同一部首漢字の記憶における分散効果: 分散呈示で自由再生・認識成績が向上（同部首・同意味の漢字および統制リスト）。間隔をあけた反復は漢字の記憶に有効。
- Leitner 方式（1972）: 正答カードは次の箱へ（間隔が長くなる）、誤答は先頭箱へ戻す。フラッシュカードの間隔反復の実装として最も単純。
- 間隔最適化の理論研究（KDD 2016 / PNAS 2019）: 忘却曲線に基づく出題間隔の最適化は記憶保持を改善する。

**設計への反映**: 箱1〜5の簡易Leitner。間隔は **1日→2日→4日→7日→15日**（小学生の忘却速度を考え短め。学期内運用前提）。児童に箱を見せる必要はなく、当日出す分を自動決定する。

### 6. 部首・構成要素の理解が記憶を助ける

- JMET 21(1): **部首理解力が漢字成績と正の相関**。部首に基づく組織的学習+指でなぞる運動学習を組み込んだシステムで部首理解力・書記能力の向上を確認。
- 漢字のパターン構造理解（構成要素のチャンク化）は未知漢字の読み・意味推測にも有効。

**設計への反映**: 漢字データに部首・構成要素を持たせ、カード裏面に「へん・かんむり」等の分解を補助情報として出せるようにする。同部首の漢字をまとめて出すモードは後続機能として枠を残す。

### 7. 「書く」の実装可能性

- **KanjiVG**: 常用漢字・教育漢字の筆順付きSVGデータ（CC BY-SA）。学年配当全1026字をカバーする。
- **ストローク判定ライブラリ**: mxggle/kanji-recognizer（KanjiVGベース、依存なしJS、ストロークごと判定・フリーライティング対応）、hanzi-writer（漢字クイズ・書き順判定で広く利用実績、kanjiverse等）。いずれもブラウザだけで動く。
- **なぞり書きの指導法研究**: Oska Writing（JALD 35(3)）— なぞり学習+1〜3画ずつの段階的提示+空書きで学習障害児の書字獲得に有効性が示唆。iPadの指/スタイラスでの粗大運動書字も許容された。
- フィードバックタイミング研究（Union College 2022）: iPad手書き漢字の書き順誤りへの即時/遅延フィードバックを比較する研究が存在し、即時フィードバックの実装は技術的に確立済み。

**設計への反映**: 「かく」は「なぞり（薄線プロンプト）→ なぞり（画順ガイドのみ）→ 単独書き（書き順判定）」の3段階。ストロークごとに即時採点し、誤筆はそのストロークをやり直させる（遅延まとめて指摘はしない）。書き上がった字の「正誤」だけでなく書き順も採点対象にする。

### 8. 書字の媒体・回数への注意点

- 紙 vs タブレットの書き取り比較: 直後テストは同等だが遅延テストでは紙学習が優位という報告あり。タブレット学習を避ける結論ではなく「練習量で補える」とする解釈が妥当。
- 筆記回数の増加は再生成績を改善しない（再掲）。**書く練習は「正しい形で1回書く質」>「回数」**。

**設計への反映**: 「かく」モードは同一字の連続反復を強制せず、正しく書けたら次の字へ。間違いはその場で正し、その字は後日の箱に戻す。

## 設計

### モード構成

| モード | 目的 | 出題 | 応答 | 採点 |
|---|---|---|---|---|
| **よむ** | 漢字・漢字語の読みの獲得・定着 | 表面: 漢字/熟語（大きく呈示） | 想起→カード裏返す | 児童の自己採点（「おぼえてる」「まだ」2択） |
| **かく** | 読みが定着した字の書字獲得 | 読み仮名/例語を呈示して書かせる | 画面に指/ペンで書字 | ストローク自動判定（書き順+形） |

- よむ→かくの流路: よむで箱3以上になった字が「かく」の出題対象になる（読み先行・遅延再生）。
- 学年配当の読みは当該学年、書きは前学年までの漢字を対象にする指導要領の構造をそのまま採る。

### 画面構成（児童）

```
[学年タブ: 1][2][3][4][5][6]      ← 既定は自分の学年（自動決定）
[今日のカード]                     ← 自動選択: 期限到来の復習分 + 新出N枚

カード面（よむ）:
  ┌─────────────┐
  │             │
  │   漢字 / 語  │  ← 大きく（フォント~120px想定）
  │             │
  └─────────────┘
  タップで裏返し → 「よみ」＋代表語＋（音声再生ボタン）
  下部2ボタン: [まだ]  [おぼえた]   ← 同一高さの大きなタップ領域（Fitts: D≈0）
```

- 新出カードの初回は裏面を自動表示（刺激ペアリング: 文字+音声+意味を同時呈示）→ 2枚目以降は想起→裏返し。
- 1セッション = 当日の復習分 + 新出数枚（既定: 新出5、復習上限は期限内すべて）。終わったら「きょうはおわり」だけ表示。

### 画面構成（教師）

- 児童ごとの箱内訳（箱1-5の枚数）・滞留字（箱1に長く残る字）・未着手字
- 週間の学習回数/新出消化数
- 設定: 対象学年・新出ペース・箱の間隔の上書き（低頻度操作のため折りたたみ内）

### データモデル

```
Kanji（静的・リポジトリ同梱）:
  { char, grade(1-6), strokes, bushu(部首), readings{on,kun}, words[熟語例] }
  ※学年別漢字配当表（1026字）を正本データとして整備。KanjiVGの筆順と結合。

Card（児童×漢字ごとの進捗）:
  { userId, char, mode(read|write), box(1-5), dueDate, lastResult, reps }
  ※正答→box+1（次回間隔を延ばす）、誤答→box1（翌日再出題）

Session（学習イベント）:
  { userId, date, cardsReviewed, newCards, correctRate }
```

### 永続化（Platform層）

- `Platform` 抽象層を挟む（理念・原則4）: 本番=GAS+Sheets、デモ=localStorage。
- GASデプロイなしでブラウザ単体で動く自己完結デモを必須条件とする（AIが手元で検証でき修正サイクルが速い）。
- 自動保存・通信断でも学習結果を失わない（原則1「失敗しない」）。

### 「書く」の技術構成

- KanjiVGのSVG筆順データを利用（ライセンス: CC BY-SA 4.0、データに帰属表記）。
- ストローク判定: KanjiVGベースの判定ロジックを自前実装（ストロークの始点・終点・経路の類似度で採点）するか、kanji-recognizer相当の軽量実装を採用。依存ライブラリは最小にし、データは同梱してオフラインで動かす。
- 段階的提示: 全画の薄線ガイド → 次に書く画のみガイド → ガイドなし（単独書き）。OW研究の「継次式/同時式」に相当する提示の切り替えを児童の認知特性に合わせられる構造だけ持たせる。

### 不変条件（原則4のアサート対象）

- 学年配当データ: 各学年の字数は 80/160/200/202/193/191 = 計1026字（学習指導要領）。データ変換時に必ず検算する。
- 箱の遷移: 正答→box=min(box+1,5)、誤答→box=1。必ずどちらかに進む。
- 新出カードは1日の既定上限を超えない（復習を優先）。

## 実装順序（段階的）

1. **よむ（MVP）**: 学年別漢字データ整備 → フラッシュカード + 簡易Leitner + localStorage デモ。
2. **かく**: KanjiVG統合 → なぞり+書き順判定 → 単独書き。
3. **教師画面**: 集計・滞留字一覧。
4. 音声読み上げ・部首分解表示などの補助機能。

## 未決事項・リスク

- **自己採点の信頼性**: よむの採点は児童の自己申告（「まだ/おぼえた」）。不正申告は復習で自然に再出題されるため致命的ではないが、教師側のテスト機能（ランダム出題で実力を測る）を後続で検討。
- **新出ペース**: 新出5枚/日は仮置き。学年と学期の進度（年間200字前後÷週数）から逆算して調整する。
- **書きの入力精度**: 児童のタッチ精度は成人未満（Brown & Anthony 2012）。ストローク判定の許容度は緩く設定し、誤判定で挫かせないことを優先する。
- **音声**: `speechSynthesis` の読み精度（音訓の出し分け）は端末依存。読みが複数ある字は代表読みを明示しておく必要がある。
