# 25. 一文の分解（旧称 ぶんの ぶんかい）（2026-10、利用者の指定による追加）

設計書 [design.md](../design.md) §25 から分けた機能別の仕様（節番号は design.md と同じ）。全体の決定（§1・§2・§13・§23・§24）は design.md が正本。

- **目的**（利用者）: 教科書の「文の成分」の学習を、提示された文を 主語・述語・修飾語・接続語・独立語 の5役割に分け、修飾語は係り先の文節も選ぶ活動として実装する。児童画面の右下の「その他」ボタンから入る（「その他」は今後の活動の入口を並べる chooser 型の画面）。
- **画面の流れ**: メニュー →「その他」→「ぶんの ぶんかい」。**1回5問**（利用者の指定）— `Sched.bunkaiPick` で、まだ答えたことがない問題を問題集の並び（易→難）どおりに、全部に答えたあとは「最後に答えた時刻」の古い順に回す。1問ごとに2段の判定: **語の役割を全部答える → 正誤判定 → 修飾語のつながりを全部答える → 正誤判定**（利用者の指定）。各段で、1回目の失敗は まちがいだけ消して正解は残す（ロック）、2回目の失敗か「わからない」は答えを出して次の段へ進む。「わからない」の問題は成長の対象に数えない（よむ・かくと同じ約束）。
- **操作**: 文節チップをおして役割パレット（主語・述語・修飾語・接続語・独立語。漢字メインに読み仮名のルビつき — 利用者の指定）で当てる。係り先の段では 修飾語チップをおして係り先の文節をおす。**おすだけの操作に統一**し、おしたまま移動（ドラッグ）は廃止した（利用者の指定）。係り線は教科書と同じ下ブラケット＋矢じり（文節の下に くの字、**矢じりは係り先の文節の辺を指す向き** — 下から来た線は下辺に上向き、上から来た線は上辺に下向き）。**同じ係り先へ向かう線は1つに束ねる**（出し手ごとの垂線＋係り先への矢じり1つ・利用者の指定）が、**係り先の違う線は束ねない**。下側に置くと垂線が他の線の横線を突き抜ける並びは 行の上側へ回す（利用者の指定。線同士が触れ合わない）。**線同士の重なり（同じ縦位置を通る線）は出さない**: 文節の辺には接続点を複数設け、同じ行間・同じ横位置の辺から出入りする垂線は辺の内側でx座標をずらして割り当てる（利用者の指定。入れ子の係り受けで同じ文節に線が出入りするときも、出る線と入る線は別の接続点を使う）。接続点の順番は相手側の文節の横位置に合わせて並べ、扇形に交わらないようにする。それでも残る垂線どうし・横線どうしの重なりは再配置・破線で避ける。行をまたぐ線は2つの行の間を通る。上下どちらに回しても触れ合う並び（めったにない）と、行を2つ以上またぐ線は破線にして混同を防ぐ。見分けはまず置き場と形で、色は補助として 係り先ごとに cat-1〜4 を回す（線色の変更は利用者より許可）。行間の広さと上下の余白はレーンの本数から計算して、線が文節にかぶらないようにする。
- **文節チップの横幅**: 全部で5文字分（188px）に統一し、行は左揃え — どの問題でも先頭の文節が同じ位置に出る（利用者の指定）。6文字以上の文節は文字サイズを自動で縮めて箱の幅を揃える（内蔵の最長は7文字。文節ごとの伸縮で先頭位置がぶれるのを防ぐ）。先生の作る画面も同じ見た目。
- **役割の見せ方**: 語バッジ（`主語/しゅご`の小さなバッジ）＋**役割ごとの色**（主語=赤・述語=緑・修飾語=青・接続語=紫・独立語=茶。利用者の指定 — 「5役割は色分けの上限を超えるので色は使わない」の前の決定を上書き。色だけに頼らず語ラベルも必ず添える。識別は color-coding の検査で確認: 赤×緑は2型色覚で潰れるため、差は形・位置・語でも併せて伝える）。役割パレットと文節のバッジを同じ色にして対応を見せる。選択中は青い枠・係り先モード中は係り先候補が点線になる（形と色の二重の手がかり）。**バッジは絶対配置** — 「修飾語→？」のような中身の幅でチップの寸法・位置が変わって文節がずれる不具合があったため、チップの大きさは文節テキストだけで決まる（バッジは狭いチップからはみ出してよい、その分を下パディングで確保）。選択・ドロップ対象の強調もボーダー幅ではなくアウトラインで行う（レイアウトが動かない）。
- **問題集（内蔵50問）**: `data-src/bunkai.txt` が正本（`id 文節=役割[>係り先番号] …`）。`npm run build:bunkai` で `src/bunkai-data.js` を生成。生成時に機械検査する: 文節2〜8・述語ちょうど1・主語高々1・修飾語は係り先番号が要る・係り先は 主語/述語/修飾語 のみ・自分自身は不可・文節の漢字は {字|よみ} の中にだけ書け3年配当まで（未習字はひらがな。利用者の指定）。文そのものは自作（インターネットの問題を そのまま移さない。文法面は教科書の係り受けの考え方に合わせて確認した）。
- **先生が自分の文を追加できる**（利用者の指定）: 先生画面「ぶんかい」区画の「問題を つくる」で、文を空白で文節に分けて書き、児童と同じ画面で役割と係り先を当てて登録（当てた内容がそのまま答えになる。解ける形か その場で分かる）。保存はゲートと同じ学級キー方式（設定シート `bunkai:<学級>` にJSON、CacheService 10分、先生が保存したらすぐ上書き → 児童には最長30秒ほど）。形の検査は `Sched.normBunkai`（児童・先生・GAS で共用の唯一の実装）。自作は内蔵の後ろに並び、最大50問。一覧から消せる。
- **記録**: 進捗の meta に `bunkai: { 問題id: [答えた回数, まちがい回数, 最後に答えた時刻, 最後にまちがえた時刻, 役割まちがい累計, 係り先まちがい累計] }`。統合は「最後に答えた時刻」の新しい方（字の記録と同じ約束）。終えた回は done/old に よむ・かくと同じ仕組みで数える（「わからない」分を除く）。
- **森**: ぶんかいの終了はモード 'b' で記録され、葉は **カードと同じ茶色** で育つ（利用者の指定。森の保存データは4色のまま、'b' はログに 'k' として落とす。モードは modes{} に残るので ぶんかいの回数は区別できる）。凡例の「葉の色」に ぶんかい（茶色・三角）を追加し、注意書きを「よむ・かく・ぶんかいで 育つよ」に変えた。
- **先生画面の分析**（利用者の指定）: 「ぶんかい」区画に、答えた人数・いま最後の答えがまちがいの児童の数（割合）・役割まちがい/係り先まちがいの累計を問題ごとにまちがいの多い順で出す（上位10。児童名は出さない — 学級の字の集計と同じ約束）。
- **ゲート**: `m.other`（その他ボタン）と `o.bunkai`（その他画面の ぶんかいボタン）をゲートの対象に足した（おためしのチップでも切り替えられる）。
- **検査**: `tests/bunkai.test.mjs`（問題集の形・漢字の学年・記録・統合・森モード・normBunkai・5問選択）、`tests/gas.test.mjs`（自作問題の保存と配信・集計）、e2e（チップがずれない・上側を通る線・同じ係り先の束ね・5問）。
