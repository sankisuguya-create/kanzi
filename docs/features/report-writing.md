# レポートを書く（設計書 §30）

全体の決定は [design.md](../design.md) §30・§28。部品は 説明文を書く（[setsumei-writing.md](setsumei-writing.md)）と共通。

## 児童
- その他 → レポートを書く → 「酒づくりの レポートを書く」。横書きの原稿用紙（1行20マス・左から右・下へ。用紙が足りなければ下へ増える）。
- はじめの用紙: 1行目 `　　　【　　　　　】のくふう`（穴を押すと穴ごと選ばれ、打つと置きかわる）、2行目 名前（右につめ、右はし1マスあけ）、見出し4つ（各見出しの直前は1行あけ、下に1マスあけた空の段落）、〈使った本〉。
- 見出しの行と直前の空き行は書きかえられない（打つ・消す・段落の入れかえ・修正案の採用で変わる時は もとに戻し「見出しは かえられないよ」と出す。`Genko.headSig` で比べる。見出しの行を押すと 見出しの下の行のはじめへ）。先生の修正案も見出しには出せない。
- 見なおす: 題名・名前／見出しの下が空（「〇〇」を書こう）／段落のはじめの1マスあけ（見出しの行と〈使った本〉から後は問わない）／【】の穴。
- 矢印キー: →次の字 ←前の字 ↓次の行 ↑前の行。
- お手本ボタンは出さない（ヒントが かわり）。旧お手本「図書館の本のならべ方のくふう」（`Genko.REPORT_SAMPLE`）は使っていない。事実: 図書館の本はなかみで0〜9に分ける（日本十進分類法）。〈使った本〉の行は「れい」と明記した架空の本。
- 段落の入れかえ・先生のコメント・修正案・友だちに見せる（レポートで1つ）は 説明文を書く と同じ。

## 先生
- 先生画面の区分タブ「レポートを書く」→「作品を見る・コメントする」。レポートだけが出る（説明文は「説明文を書く」で見る）。印刷は B4 横に横書きの用紙。

## 検査
- `tests/genko.test.mjs`（テンプレート・見なおし）、`npm run e2e:report`（通し操作・横書きの向き・先生画面・印刷）。

## 役わり分け（利用者の指定）
- **レポートを組み立てる**（練習）: 「ふでばこの道具」の作文例を えらんで組み立て、つながりが合うかを確かめる。
- **レポートを書く**（本番）: その経験を元に、社会の「西宮の酒づくり」でレポートを書く。お手本を まるごとは見せない。難しい児童は、見出しごとのヒントを自分で1段ずつ開く。
  - ヒント1＝何を書くか（ア〜ウの見出し）→ ヒント2＝文を読む → ヒント3＝文を本文に入れる（【　】は自分のことばに かえる穴。見なおすで穴が残っていると指摘）。
  - 作文例は `Genko.REPORT_EXAMPLES`（事実は地域教材にあるものだけ）。先生画面の「レポートを書く」の作品画面で全部を見られる。
  - 先生が段階を切りかえる仕組み（旧 repStage）は やめた。
- （１）（２）で始まる小見出しの行は、1マスあけを問わない。

## レポートを組み立てる（その他。ゲート `o.kumi`）
- はじめに「自分で えらんで組み立てる」か「合っているか見分ける もんだい」を選ぶ。もんだいは、作文例を組み合わせたレポートを横書きで見せ、①「合っている／合っていない」を判定 → 正誤と理由、合わない見出しにしるし。②合わない時は、見出しごとに ア〜ウを えらびなおし「合っているか たしかめる」→ 合えば できあがり。記録は残さない。
- 判定（`Genko.kumiCheck`）: ４↔３（同じ記号）／３ア「本には」→２イ（本）／３ウ「先生に聞くと」→２ウ（人）／１ア（えんぴつ）→３ア／１ウ（あな・切りこみ）→３アか３ウ。81通りのうち合うのは8通り。問題は合う・合わないが半々になるように出す（`kumiProblem`）。
- 書く画面の「📄 見本を べつの まどで ひらく」: 酒づくりの作文例のアを組んだ見本を、別のまど（横書き・大きな字）で開く。まどが開けない時は 左に見本を出す。学校の GAS（iframe の中）で別のまどが開くかは未確認。
