# レポートを書く（設計書 §30）

全体の決定は [design.md](../design.md) §30・§28。部品は 説明文を書く（[setsumei-writing.md](setsumei-writing.md)）と共通。

## 児童
- その他 → レポートを書く → 「レポートを書きはじめる」。横書きの原稿用紙（1行20マス・左から右・下へ。用紙が足りなければ下へ増える）。
- はじめの用紙: 1行目 `　　　【　　　　　】のくふう`（穴を押すと穴ごと選ばれ、打つと置きかわる）、2行目 名前（右につめ、右はし1マスあけ）、見出し4つ（各見出しの直前は1行あけ、下に1マスあけた空の段落）、〈使った本〉。
- 見出しの行と直前の空き行は書きかえられない（打つ・消す・段落の入れかえ・修正案の採用で変わる時は もとに戻し「見出しは かえられないよ」と出す。`Genko.headSig` で比べる。見出しの行を押すと 見出しの下の行のはじめへ）。先生の修正案も見出しには出せない。
- 見なおす: 題名・名前／見出しの下が空（「〇〇」を書こう）／段落のはじめの1マスあけ（見出しの行と〈使った本〉から後は問わない）／【】の穴。
- 矢印キー: →次の字 ←前の字 ↓次の行 ↑前の行。
- お手本「図書館の本のならべ方のくふう」（自作。テスト・教科書の文はうつさない）。事実: 図書館の本はなかみで0〜9に分ける（日本十進分類法）。〈使った本〉の行は「れい」と明記した架空の本。
- 段落の入れかえ・先生のコメント・修正案・友だちに見せる（レポートで1つ）は 説明文を書く と同じ。

## 先生
- 先生画面の区分タブ「レポートを書く」→「作品を見る・コメントする」。レポートだけが出る（説明文は「説明文を書く」で見る）。印刷は B4 横に横書きの用紙。

## 検査
- `tests/genko.test.mjs`（テンプレート・見なおし）、`npm run e2e:report`（通し操作・横書きの向き・先生画面・印刷）。

## 段階と作文例（写す→えらぶ→かえる→自由）
- 先生がレポートの作品画面の左で、学級ごとに段階を選ぶ（設定のキー `repStage:<学級>`、空＝自由）。児童には、メニューから入り直した時に届く。「児童画面を ためす」は、先生がその端末で最後に見た・決めた段階で開く。
- 作文例は `Genko.REPORT_EXAMPLES`（社会「西宮の酒づくり」。事実は地域教材にあるものだけ）。見出しごとに3つ（ア・イ・ウ）。
  - 写す: 左に見本（各見出しのア）を出す。「お手本を見る」も この見本になる。
  - えらぶ: 見出しごとにア〜ウを押すと、その見出しの下の本文が入れかわる（見出しと空き行はそのまま）。組み合わせは自由で、３に合わない４も選べる（違和感に気づかせるため。利用者の指定）。
  - かえる: えらぶと同じだが、作文例の一部が【　】の穴になって入る。見なおすで穴が残っていると指摘。
  - 自由: 見出しだけの用紙（今までどおり）。
- （１）（２）で始まる小見出しの行は、1マスあけを問わない。
- 合う組み合わせ: ３ア↔４ア、３イ↔４ウ、３ウ↔４イ。
