# 28. 説明文を書く（2026-11、利用者の指定による追加）

設計書 [design.md](../design.md) §28 の仕様。要件と決定の経緯は [requirements/setsumei-writing.md](../requirements/setsumei-writing.md)。全体の決定（§1・§13・§23・§24）は design.md が正本。

**実装の段階**（利用者の決定）: 1回目＝書く・見なおす・お手本・自動保存・先生の一覧と1人の表示・段落ごとのコメント・読み合い。2回目＝先生の修正案（赤字で重ね、児童が「なおす」で採用する: W2）。2回目は 1回目を実機（CZ1104）で使って、縦書きの入力に問題がないか確かめてから作る。

## 児童
- **入口**: メニュー →「その他」→「説明文を書く」（ゲート `o.sakubun`）。作品の一覧・「テンプレートで書く」「白紙に書く」「お手本を見る」・（読み合いが開いている時だけ）「友だちの文を読む」。
- **作品はいくつでも**（利用者の決定）。友だちに見せるのは1人1つ（「この文を友だちに見せる」を入れると、自分のほかの作品は外れる）。消すと一覧から消える（シートの行は残し、型を `del` にする）。
- **書く画面**: 左に操作（もどる・お手本・見なおす・指摘・見せる・先生のコメント・保存の表示・原稿用紙のきまり・消す）、右（7割以上）に原稿用紙。幅 760px 未満は上下に並べる。
- **原稿用紙**（`src/genko.js` の `layout`。一般的な書き方に合わせた。出典は下）:
  - 400字づめ（20マス×20行）。右の行から左へ。20行を超えたら左に2枚目。用紙の中だけを左右にスクロールし、最初は右端（書き始め）。
  - 1マス1字。改行（段落）は次の行から。小さい「ゃゅょっ」も1マス（右上に寄せる）。
  - 「、」「。」「」」などは行の頭に書かない → 前の行の最後のマスの右下に、字といっしょに。「「」などは行の最後のマスに書かない → 次の行へ。
  - 1行目＝題名（上を3マスあける）、2行目＝名前（下につめ、いちばん下は1マスあける。名字と名前のあいだも1マス）、本文は3行目から。題名・名前の位置は資料によって説明がまちまちで、あけるマスの数を明記した資料は見つからなかった。例として示されていた形に合わせた。
- **入力**: 字は見えない入力欄（textarea）で受け、マス目に描く。マスを押すとそこにカーソル。変換中の字はマスの中に青い下線で出す。矢印は縦書きの向きに読みかえる（↓次の字・↑前の字・←次の行・→前の行）。半角は全角に直す。テンプレートの【】の中を押すと穴ごと選ばれ、打つと置きかわる。
- **テンプレート**（利用者の指定）: 題名「すがたをかえる【食材】」、はじめ「【食材】には、いろいろな食べ方のくふうがあります。」、中は空の段落3つ、おわり「このように、【食材】は、くふうされて、いろいろなすがたになって食べられているのです。」。名前の行は名簿の名前（なければ空）。1か所に入れても ほかの【食材】には入らない（利用者が了承）。
- **見なおす**（`Genko.check`。押した時だけ出す）: 題名がない／題名の上をあけていない／名前がない／段落のはじめを1マスあけていない／【】が残っている。指摘は左に語で並べ、用紙の上は該当する行を わくで囲み、最初の1つにだけタグを付ける。段落は「◯番目の段落」と言う（改行で数えた番号は原稿用紙の行と食い違うため）。1字下げは自動で入れない（W4）。
- **お手本**: 自作の「すがたをかえる葉っぱ」（高木 北子）。茶の葉が 緑茶・ウーロン茶・こう茶・まっ茶になる例。原稿用紙1枚に収まる。教科書の文はうつさない（§27 と同じ方針）。
- **保存**: 打つたびに端末へ控え（`kanzi.saku.<メール>`、まだ届いていない分に dirty の印）、3秒ごと・もどる時・画面を閉じる時にサーバーへ送る。通信できない時は控えで書き続け、次に開いた時に送る（控えの方が新しければ控えを使う）。
- **段落の入れかえ**（2026-11 利用者の指定）: 左の「↔ 段落の じゅんばんを かえる」→ 用紙の段落を押してえらぶ（その段落のマスを囲む。題名・名前の行はえらべない）→「→ 前へ」「← 後ろへ」で となりの段落と入れかわる →「できた」。入れかえ中は字を打たない。先生のコメントの付け先も一緒に移す（`Genko.moveParagraph`・`composeMap`。保存の時に移し方 remap を送り、サーバーはロックの中でコメントの列を読み直して移す）。
- **コメント**: 先生のコメントは段落の上に 💬、左に一覧。「よんだ」で閉じる。
- **友だちの文**: 先生が読み合いを開いている間だけ、同じ学級の「見せる」作品の本文を読むだけで見られる（§1 の例外。メール・コメント・字数は送らない）。

## 先生
- 先生画面の区画「説明文を書く」→「作品を見る・コメントする」。左に 読み合う（オン／オフ）と児童の一覧（書いていない児童を上に。作品ごとにカード: 題名・字数・段落数・更新・見なおしの指摘の件数・見せる作品か）、右に選んだ作品の原稿用紙（見なおしの指摘も わくで出す）。
- 段落の上の「＋」でその段落へのコメントを書く（200字まで。消せる）。児童が よんだかどうかも出す。
- 先生画面の区分タブ「説明文を書く」の中にある。
- **おためしの作品**: 「児童画面を ためす」で書いた作品は、ほかの記録と同じく その端末だけに残り、サーバーへ送らない。先生画面の一覧のいちばん上に「おためし（この端末だけ・児童には届きません）」として点線のカードで出す（2026-11: おためしで書いて先生画面に出ず「見られない」となったため）。
- 読み込みに失敗したら、エラーの文と「gas/ の5ファイルを同じ版で貼り直したか」の確認、「もう一度 読む」を出す（以前は「よみこみ中…」のまま止まっていた）。

## データ（シート「作文」）
`作品, メール, 学級, 本文, 型, 見せる, コメント, 更新`（1作品＝1行）。
- 児童の保存は 学級・本文・型・見せる・更新 の列だけ、先生は コメント の列だけを書く（W5: 相手の列を古い値で上書きしない）。どちらもスクリプトロックの中で読み直してから書く。
- 児童は自分の作品だけ書ける（ほかの児童の作品番号で保存すると拒否）。先生は担当学級の作品だけ（`requireClass_`）。
- 読み合いは設定のキー `sakuShare:<学級>`。
- **学級の列は文字で書く**（2026-11 の不具合）: "3-1" をそのまま書くと、スプレッドシートが日付（3月1日）に読みかえ、先生画面・友だちの文の絞り込みで作品が1つも出なかった（児童は提出の操作なしで自動保存されていたが、先生から見えなかった）。書く時は先頭に `'` を付け、読む時は いまの名簿の学級を使う（名簿にいなければ列の値を戻す: 日付なら 月-日）。直す前に保存された行も、そのまま先生画面に出る。本文は全角にそろえるので、数字や記号が日付・数式に読みかえられることはない。
- 過年度（§24）: 「残す」で `作文YYYY` に写す。「まとめて消す」で メールを名簿と同じ番号に、本文の2行目（名前の行）を空にする。本文のほかの場所やコメントに書いた名前は見分けられないので消えない（消す画面に書く）。
- `gas/Genko.js` は `src/genko.js` の写し（`npm run build:gas` が作る）。サーバーでも `Genko.normWork` で形をそろえる（本文4000字まで・コメント200字まで）。
