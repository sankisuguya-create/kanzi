# 26. れんしゅうプリント（漢字テストの練習）（2026-10、利用者の指定による追加）

設計書 [design.md](../design.md) §26 から分けた機能別の仕様（節番号は design.md と同じ）。全体の決定（§1・§2・§13・§23・§24）は design.md が正本。

- **目的**（利用者）: 次の漢字テストと同じ形のプリントで練習する。テストと全く同じ問題ではなく、同じ字を別の短文で問い、紙のテストに般化させる。
- **入口**: 「次の漢字テストの はんい」の画面に「れんしゅうプリント 50問／10問」。出す字は、先生が指定したテストの範囲（範囲がない時はボタンを出さない）。ゲートのキー `t.p50`・`t.p10` で先生が止められる。
- **画面は3つ**（利用者の指定）:
  1. **プリント全体**: 50問（10問版は10問）を縦書き・右から左へ1行10問で一覧（答える欄は出さない）。問題を押すと、その問題を含む10問へ。
  2. **10問**: 大きな字で横一列（画面より広いので横にスクロールする前提。右端から見せる）。上に「プリント全体へ」「← 前の10問」「次の10問 →」。
  3. **答える**: 10問の画面で問題を押すと右に開く（10問の列は見えたまま、押した問題が見える位置まで動く）。「まえ」「つぎ」は その10問の中で動く。
- **1問＝1字**（利用者の指定）: 答えるのは漢字1字（送りがなの問題は ＋ひらがな）。2字の語は、もう1字をそのまま見せる。
- **問題文は短文で、答えが一意**（利用者の指定）: 正本 `data-src/tprint-g1.txt`〜`g6.txt`（1026字・1942文。1字に2文前後、送りがなの問題になる文を含む）。`npm run build:tprint`（`tools/build-tprint.mjs`）が検査して `src/tprint-data.js` を作る。通らない文は書き出さず、四角の問題が1つもない字があればエラー。検査:
  - 文の中のほかの漢字は その学年までの配当漢字（それ以外は `{字|よみ}` でルビ）。3字以上の短文。
  - 形態素解析（kuromoji・IPADIC）で辞書の語だけで読め、四角の字の読みが ルビと合う（1字だけの語は解析の読みがぶれるので ルビを正とする）。
  - **一意性**: 四角の字を、同じ読み（連濁・半濁・促音化を含む）を持つ その学年までの配当漢字に入れ替え、辞書の語だけで・同じ区切りと品詞で・同じ読みになる文が1つでもできれば使わない。入れ替えの対象を「その学年まで」にするのは、その学年の子が答えに書けるのは その学年までの字だから（1年の「□を見る（した）」に6年の 舌 は入らない）。
  - 辞書の上では語になるが 文の意味から入らない字は、目で確かめて `!字` で除ける（例: 「赤組に まける」の 巻ける）。除けた判断は `docs/reports/tprint-report.txt` に全部出す（120件）。両方とも正しい日本語になる組（手を挙げる／上げる、私立／市立、象／像の鼻 など）は除けずに、その文を使わない。
  - **確度**: 機械の検査（辞書）＋目視。辞書にない言い回し、辞書の読みの誤り、目視の見落としは残りうる。数学的な一意性ではない。
- **問題の選び方**（`src/tprint.js`。乱数を引数で受け、`tests/tprint.test.mjs` で検査）: 50問＝四角の問題40＋送りがなの問題10（最後。点線で区切った行）。10問＝8＋2。範囲の字を1つずつ、その子が「書く」で まちがえたことのある字を先に（送りがなの問題で出た字は、四角の問題では後に回し、なるべく多くの字を出す）。**答えが見える組は作らない**（利用者の指定）: ある問題の文の前後（ルビつきの字も含む）に、そのプリントの別の問題の答えの字を出さない（「感□文」と「□心する」のような組）。文を1つ選ぶたびに「答えにした字」と「文に出ている字」を見て、組めない文は使わない。その分、出せない字が増えることがある（3年9・10月の64字で50問なら 50字前後）。範囲の字が問題数より多い時は全部は出せない（3年9・10月の範囲は64字）。同じ文は2回出さない。開くたびに文と並びを入れかえる（「新しい プリント」）。
- **答え方**（利用者の決定）: **漢字は手書き**。キーボードで変換させると、字を見分ける練習になり、書く練習（紙のテスト）に般化しないため。書いている間は判定しない（`Ink.Recorder`。1画ごとに判定すると書きながら答えが分かってしまう）。「1画もどす」「けす」で直せる。送りがなは 読むと同じく ローマ字を自動でひらがなにする。書いた字は プリント・10問の四角に小さく写る。書きかけは端末に保存し、同じ範囲・同じ問題数なら続きから開く（保存の形を変えたら `TP_VER` を上げ、古い書きかけは作り直す）。
- **丸つけ**: 書いていない問題があると、1回目は「まだ○問」と案内し、もう一度押すと丸つけ。漢字は `Ink.grade`（「書く」と同じ許容・学級の判定の強さ。全部の画に当たり余った線がなければ正解。**書き順・書く向きは問わない** — 紙のテストでは見えないので、紙のテストと同じ基準）、送りがなは文字の一致。問題ごとに○×、点数（正解数×100÷問題数）、まちがえた字。まちがえた字は ボタン1つで「選んだ漢字」に入れられる。問題を押すと 答えと書き順が見られる。
- **記録**: 書いた字は「書く」の記録（間隔反復の箱）に入る（何も書いていない問題は数えない）。森は 書いた問題の数だけ 書くと同じく育つ。
- **問う字は、テストの範囲のうち いちばん上の学年の字だけ**（利用者の指定。3年のテストなら3年の字だけ）: 範囲には「作業」「休日」のような2字の語の 下の学年の字（作・休）も入るが、それはテストで問う字ではないので出さない（`printChars`）。写真の3年9・10月の範囲（73字）なら3年の45字。50問に字が足りない時は、同じ字を別の文で出す（答えが見える組を作らない範囲で）。文を選ぶ時は、まだ問うていない範囲の字が前後に少ない文を選ぶ（「荷物」の 物 のように、文に出た字はもう問えなくなるため）。写真のテストの45字は どの回も全部出る（`tests/tprint.test.mjs`。そのために 勝・暗・写・真 に 範囲の字を含まない文を足した）。
- **二文字モード**（利用者の指定。2字とも書く・範囲の熟語すべてから・○×は1字ずつ・点は2字そろって）: `tools/build-tprint.mjs` が、四角の字を含む解析の語がちょうど2字で となりがルビなしの その学年までの字なら、文に `[向き, となりのよみ]`（よみ＝語の読みから四角のよみを除いた残り）を足す。`TPrint.make(..., { jukugo: true })` はその文だけを使い、となりの字も四角にして文から除く。となりの字も「答え」として 答えが見える組の検査に入れ、同じ熟語は1回だけ。20問・送りがなの問題なし。答えは `ans.s`（1つ目の四角）・`ans.s2`（2つ目）。丸つけの ○× は `result.items[i].ks`（字ごと）で見せ、点は2字そろった問題だけ（`ok`。分母は問題の数）。まちがえた字は1字ずつ出す。保存のキーは `kanzi.tprint.<メール>.20.j`。ボタンの オン・オフは `t.juku`。四角の字を含む2字の語がない字（係・祭・命・第・役・取・畑・終・福・起・苦 など、3字の語・送りがなつきの語だけの字）は このモードでは出ない
- **残りの問題は 出題範囲の別の字**（利用者の指定）: 問う字を全部出しても50問に空きがある時、同じ字をくり返す前に、出題範囲の別の字を出す。出題範囲は「その学年の並び（出題順）で、問う字のうち いちばん早く習う字から いちばん遅く習う字までの間」と予測する（`printExtra`）。写真の3年9・10月のテストでは 物（6番目）〜役（135番目）の130字。問う46字のうち40字は 2学期の 両〜役（96〜135番目）に固まっていて、1学期の 物・意・全・鉄・送・感 は「荷物」「注意」のように 2学期の字との語で出ているため、範囲が1学期まで広がる。
- **送りがなの問題は、テストで送りがなを問う字だけ**（利用者の指定）: 先生画面「漢字テストの範囲」で、字を押した時の動きを「範囲に入れる・はずす」「送りがなで出す（送 の印）」から選ぶ。印は範囲の字の中だけ（印をつけると範囲にも入り、範囲からはずすと印も消える。サーバーでも検査 — `api_setTests`）。印があるテストでは、送りがなの問題は印の字だけから、四角の問題は印のない字だけから出す（テストと同じ問われ方で練習する）。印がないテストは これまでどおり範囲のどの字からも出す。
- **丸つけの見せ方**（利用者の指定）: プリント全体に 1問目から順に ○× をつけていき（50問は1問0.11秒、10問は0.28秒。動きを減らす設定の端末では一度に）、最後にポップアップで 点数と まちがえた字を大きく出す。ポップアップから まちがえた字を「選んだ漢字」に入れられる。とじると プリントの上に点数が残る。
- **紙で練習**（利用者の指定。どの学年にも出す。ゲート `t.paper`）: れんしゅうプリントと同じ作り方の50問・10問を画面に出し、子どもはノートに書く。「答えを見る」で四角に答えの字（と送りがな）を出して自分で答えあわせする。記録しない（自己採点を記録にすると申告がゆがむ — §1）。
- **ヒントモード**（2026-10、利用者の指定。ゲート `t.hint`）: プリントの上の「ヒント（2画めまで）」で切り替える（丸つけ前ならいつでも。プリントごとに書きかけと一緒に保存）。オンの間は どの問題も 2画目までを うすい灰色で先に書いておき、児童は3画目から書く。画数が2以下の字は最後の1画を残す（`min(2, 画数−1)` 画。「一」はヒントなし）— 書かずに正解にならないようにするため。丸つけは 先に書いた画（お手本の線を `Ink.pathPoints` で点にしたもの）を足して `Ink.grade` で判定する。
  - **記録**（利用者の決定）: 1回でもヒントをオンにしたプリントは「ヒントあり」。ヒントありの点はテスト本番の力より高く出るので、先生画面「テスト練習」の平均点には入れず、回数だけ別に出す（`tp` の値 `[点, 問題数, 1]`）。「書く」の記録（箱・まちがいの多い字）にも入れない。森は ヒントなしと同じく育つ。
  - 先生は「児童画面のボタン」で学級ごとに止められる（オフの間は 児童の画面にボタンを出さず、ヒントも出さない）。
- **未確認**: 児童の実際の筆跡での判定精度（§10）。1画ごとの書き直しがない分、「書く」より厳しくなりうる。
