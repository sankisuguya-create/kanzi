# kanzi — 先行研究と根拠

[design.md](design.md) の各決定が参照する根拠の一覧。design.md では `R番号` で引く。

- **対象**: 研究の対象集団。本アプリの利用者（日本語母語・通常学級の小学生）と違う集団の知見は、効果量をそのまま持ち込まない。
- **検証**: ✓＝書誌と主張を確認済み ／ △＝書誌は確認、主張の一部（数値・詳細）は未確認 ／ ？＝書誌自体が未確認（2026-09時点。原典に当たれたら更新する）

### 根拠の強さについての読み方

- **通常学級の日本語母語児童を対象にした直接の証拠は R6・R7・R8 だけ**で、うち R8（最も生態学的妥当性が高い）は反復・想起練習の優位を再現していない。間隔反復や想起の仕組みは「害が小さく、安く作れる既定値」として採り、効果を約束する根拠としては扱わない。
- R2・R3・R5・R14 は成人・第二言語学習者・障害のある児童の知見。方向（目視・空書き・刺激ペアリング・段階的提示が使える）だけを借り、効果量は借りない。
- 「日本語母語の児童は読みより書きの正答率が大きく低い」という見立ては、ベネッセ「小学生の漢字力に関する実態調査」(2007/2013) が該当しうるが、**原典の数値を未確認**（2013年調査は書きテストのみで全体正答率59.0%）。設計の優先順位をこの見立てに依存させない。
